# SomeKinda Game 🎲

A 2-player dice roll game with randomly generated outcomes. Roll the dice, rack up points, and the highest score wins.

## Features

- 2-player support
- Random dice roll on click
- Score tracking per player
- Hand-drawn visual style
- Multiple dice style options

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Play

1. Open `index.html` in your browser
2. Players take turns clicking to roll the dice
3. Scores accumulate each round
4. The player with the highest total score wins
